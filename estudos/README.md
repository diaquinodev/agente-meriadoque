# Estudos — como esta pasta funciona

Cada arquivo aqui é um **estudo de caso**: algo real que fizemos no projeto,
explicado de forma didática. A ideia é você jogar esses arquivos no **NotebookLM**
e montar seu plano de estudo a partir deles.

## Nome dos arquivos

`caso-NN-assunto-curto.md` → ex: `caso-01-montando-o-agente.md`

Numeração em ordem cronológica, assim você vê sua evolução.

## Estrutura de cada estudo de caso

1. **Contexto** — o problema que tínhamos.
2. **O que fizemos** — passo a passo, com os comandos reais.
3. **Conceitos** — cada termo técnico explicado com uma analogia.
4. **Por que assim** — decisões tomadas e alternativas descartadas.
5. **Hacks e pegadinhas** — o que dá errado na vida real.
6. **O que estudar** — tópicos em ordem de prioridade.
7. **Perguntas para o NotebookLM** — perguntas prontas para você se testar.
8. **Referências** — só fontes oficiais ou reconhecidas.

## Como usar no NotebookLM

1. Crie um caderno "Engenharia de IA — Meriadoque".
2. Adicione os arquivos desta pasta como fontes (e o `docs/GUIA-DO-AGENTE.md`).
3. Use as perguntas da seção 7 de cada caso.
4. Peça ao NotebookLM: "Monte um plano de estudo de 4 semanas com base nessas fontes".
5. Gere o resumo em áudio para ouvir no trânsito.

## Regra para os agentes

Só crie um estudo de caso quando houver aprendizado real. Prefira atualizar um caso
existente a criar um novo e raso.
